## 简体中文版

本项目基于 [DnG-Crafts/K2-RFID](https://github.com/DnG-Crafts/K2-RFID) 修改而来，针对 Creality（创想三维）K2 / K1 / HI 打印机的 CFS 耗材系统，重构了核心的交互逻辑与 NFC 读写安全机制。

### ✨ 核心改进与特性

相比于原版，本项目重点修复了操作体验上的痛点，并增强了底层写入的安全性：

- 🔄 **真·四级联动选择**：主界面严格遵循 **打印机 → 品牌 → 类型 → 名称** 的层级过滤，最终精准映射到唯一的耗材 `base.id`，彻底解决错选、乱选问题。
- ⚖️ **自定义重量输入**：打破原有的 5 个固定重量预设限制，现在支持直接输入 **1–1000g** 的自定义克数，程序会自动计算并转换为标签所需的长度编码。
- 🛡️ **防手抖的“碰一碰”写入**：点击写入后，不再要求手机必须一直贴着标签。应用会弹窗等待，你拿着手机去碰触标签，识别后**自动写入**。
- ✅ **回读校验，拒绝假成功**：写入完成后，程序会立即回读 Sector 1 和 2 进行数据比对，只有完全一致才提示成功。若中途移开手机，会精准报错并提供“重试”按钮。
- ✏️ **支持修改耗材 ID**：在编辑页面可以直接修改耗材 ID（5 位纯数字）。修改时，程序会自动同步更新 `kvParam.filament_notes` 中的 `RFID=` 标记，防止被 K2 Pro 固件强制回滚。
- 🔍 **反向智能恢复**：碰触已有标签读取时，通过读取标签上的 ID，自动反向恢复并选中界面上对应的打印机、品牌、类型、名称、重量和颜色。

### 🔗 配套工具：与 K2_Pro_RFID_Material_Sync 协同工作

本应用专注于 **RFID 标签的物理写入与 ID 管理**。但要让打印机在读取标签后，真正识别并使用你自定义的耗材参数（温度、流量、压力提前量等），还需要将耗材配置文件同步到 K2 Pro 的本地数据库中。

配套工具 [**K2_Pro_RFID_Material_Sync**](https://github.com/ccrx-service/K2_Pro_RFID_Material_Sync) 正是为此设计：它负责将切片软件（OrcaSlicer / Creality Print）中的耗材配置推送到打印机，而本应用负责把**对应的耗材 ID** 写入 RFID 标签。

**两者的协同工作流：**

1. **在切片软件中**：为耗材配置设置一个唯一的 `id`（或在 notes 中标注 `RFID=xxxxx`）。
2. **使用 K2_Pro_RFID_Material_Sync**：将耗材配置同步到 K2 Pro 打印机。
3. **使用本应用**：选择同一耗材，将**相同的 5 位 ID** 写入 RFID 标签。
4. **在打印机上**：刷标签时，打印机根据 ID 在本地数据库中查找对应的耗材参数，实现自动配置。

> ⚠️ **关键点**：两个工具通过 **耗材 ID** 关联。如果切片软件中的耗材 `id`、本应用写入的 `base.id`、以及 `filament_notes` 中的 `RFID=` 值不一致，打印机将无法把 RFID 标签与耗材配置正确对应。本应用在修改 ID 时会自动更新 `filament_notes`，正是为了保证这一链路的完整性。

请前往 [Releases](https://github.com/你的GitHub用户名/你的仓库名/releases) 页面下载最新版本的 `.apk` 安装包。

### 📱 使用指南

1. **写入标签**：在主界面选好耗材、输入重量后，点击“写入”。此时不要贴标签，等屏幕弹出等待框后，再将手机靠近标签。
2. **读取标签**：将手机靠近已写入的标签，点击界面的“读取”（或开启自动读取），界面会自动跳转并显示耗材信息。
3. **修改 ID**：点击右上角的编辑按钮，在顶部的“耗材 ID”框中输入新的 5 位数字，保存即可（后续请使用新 ID 写入标签，并确保同步工具的配置也使用相同 ID）。
